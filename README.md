# Jellydroid

**让你的 Jellyfin 片库更好逛、更好看，也更好整理。**

Jellydroid 是基于 [Findroid](https://github.com/jarnedemeulemeester/findroid) 打造的第三方 Jellyfin Android 客户端，面向手机、平板与折叠屏优化。在原生浏览与播放体验之外，**特别针对日本电影使用场景优化**，将番号抓取、中文翻译、封面管理与演员资料整理融入日常观影流程。

连接自己的 Jellyfin 服务器，从挑选影片到补全资料、播放与离线下载，都能在移动端完成。

## 为什么选择 Jellydroid

- **找片更有方向**：从演员、类型、标签、年份或制片公司进入片库，也可以随机浏览，发现下一部想看的作品。
- **资料整理更省事**：按番号抓取影片信息与封面，翻译日文标题和简介，确认后保存到服务器。
- **随时接着看**：支持多版本选择、ExoPlayer / mpv 双播放后端，以及后台下载与断点续传。

## 针对日本电影使用场景优化

围绕“按番号整理、按演员找片、看懂日文资料”的使用习惯，把常用工具放进电影详情页。

### 按番号补全影片资料

在「编辑 nfo」中输入番号，即可从已配置的站点抓取标题、简介、类型、发行日期、评分等信息。支持多个站点同时抓取，并在不同来源的结果间切换选择，减少手动查找与复制粘贴。

标题、原名、简介、类型、标签、制片公司、演员与导演等资料，也可以直接手动编辑。抓取结果先回填表单，确认保存后才写入服务器。

### 把日文标题和简介变成中文

支持将抓取结果或表单中的日文标题、简介翻译成简体中文，也可开启抓取后自动翻译，让片库更容易浏览与理解。

翻译使用自行配置的 OpenAI 兼容接口，可接入 DeepSeek 等服务；需填写接口地址、密钥与模型，配置保存在本机。

### 为影片挑一张合适的封面

- **抓取封面**：按番号获取多个站点的横图与竖图，预览后选择上传。
- **查看现有图片**：集中查看服务器上的影片图片，支持全屏预览与双指缩放。
- **用喜欢的画面做封面**：播放时截取当前画面，上传为横屏封面。

### 从喜欢的演员找到更多作品

点击演员即可查看片库中该演员的作品；也支持按导演、编剧浏览。长按演员条目可按名字抓取候选头像，选择后上传，让人物列表更直观；也可复制完整演员名，方便继续搜索或整理资料。

抓取站点地址可在电影详情页「更多 → 抓取网址」中配置，保存后即可在当前页面使用，抓取时也可单独设置代理。发布版不内置站点地址，使用前需自行配置；未配置的站点会跳过，实际可获取的资料取决于站点收录与网络情况。

## 更好逛的媒体库

- **多种浏览入口**：按类型、标签、分级、年份、演员、导演、编剧与制片公司查看作品；详情页中的类型与标签也可直接点击浏览。
- **封面随心切换**：在竖版海报与横版剧照之间切换，搭配排序与随机浏览，用自己喜欢的方式挑片。
- **收藏也能按习惯浏览**：「我喜欢」页支持排序与海报 / 剧照切换，并与媒体库列表共用偏好，减少重复设置。
- **页面切换更连贯**：电影列表封面与详情页图片平滑衔接，文字和操作按钮依次淡入；底部标签即时切换，按住返回手势时详情画面保持稳定。
- **大小屏都舒展**：首页轮播随屏幕宽度调整布局，兼顾手机、平板与折叠屏；详情页背景图按原图比例完整展示。
- **详情清楚易读**：长标题可展开或收起，电影详情页可查看本地与服务器文件路径，方便确认片源。
- **合集一眼可辨**：合集卡片带专属角标，缺少封面时自动借用内部作品图片。
- **搜索少些等待**：缓存搜过的关键词结果，来回切换时更方便。

## 更顺手的播放体验

- **双播放后端**：支持 ExoPlayer 与 mpv，按使用需求选择。
- **多版本选择**：同一影片有多个文件时，播放前可选择版本，并区分本地与服务器文件。
- **常用控制集中**：字幕、倍速与音轨集中在播放菜单中，透明控制栏减少画面遮挡。
- **亮度按习惯来**：手动调整后才记忆亮度，未调整时沿用系统亮度。

## 下载后，离线也能看

- **后台持续下载**：离开下载页面后仍可继续，通知栏显示进度。
- **支持断点续传**：下载中断后可接着下载，减少重复等待。
- **多分片并发**：服务器支持时启用多分片下载，不支持时自动使用单连接。
- **状态清楚可见**：显示实时速度与排队、暂停、失败、完成等状态；已下载条目可查看本地文件路径。
